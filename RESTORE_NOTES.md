# Tiklash eslatmasi

Bu loyiha eski `park-map-loyiha.zip` ustiga tiklangan. Quyidagilar QAYTA TIKLANGAN (kod bor):
- `src/map/Fountain.tsx` — favora maydoni va 4 pog'onali sharshara
- `src/map/DamFountain.tsx` — 8 ta granit poydevorli fontan
- `src/map/SwanStatue.tsx` — oqqush haykali
- Basseyn shakllari (`data/map.geojson`, `data/pools-shape.geojson`), soyabonsiz shezlonglar
- Cars, Merry_go_round, Excavator, Aqua_Lady_Birds nomlari (pin)

Quyidagilar bu zipda YO'Q (kodi yo'qolgan), lekin `reference/park-map-client.html` da ishlaydi:
Avtodrom, Sahna (+skameykalar), Wind (Aqua Lady Birds modeli), Samolyot/Bolalar/Daraxt karuseli, GameLand,
bolalar maydonchasi rejasi (halqalar, uychalar, panjara), Loops_Coaster, Karusel markazi atrofidagi o'zgarishlar.

Ishga tushirish: `npm install && npm run build:map && npm run dev`
